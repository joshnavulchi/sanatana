# Install dependencies
npm install

# Generate keywords (Google Trends only)
npm run generate-keywords

# Or directly
node scripts/generate_keywords_with_trends.js

1. User runs: node scripts/generate_keywords_with_trends.js
2. Script reads JSON file
3. Extracts 2-5 title words (minimal context)
4. Calls Google Trends API with Indian spiritual topics
5. Filters results strictly (scriptures, gods, sages, philosophy)
6. Removes duplicates
7. Writes unique trending keywords to meta.keywords
